# DreamMax Remote - Setup Guide

## 📱 Step 1: Install the App on iPhone

1. **Open this link in Safari:**
   ```
   https://dragonsword1-max.github.io/remote-dreammax/
   ```

2. **Tap the Share button** (square with arrow pointing up)

3. **Scroll down and tap "Add to Home Screen"**

4. **Name it "DreamMax Remote"**

5. **Tap "Add"** (top-right corner)

6. ✅ **Done!** The app icon is now on your home screen

---

## 🔍 Step 2: Find Your DreamMax IP Address

### Using Fing App (Recommended)

1. **Download "Fing"** from App Store (free)

2. **Open Fing** and let it scan your network

3. **Look for DreamMax** in the device list:
   - Search for names like: "DreamMax", "B9S2X", "Beout", "Enigma", "Receiver"
   - Or look for devices categorized as **"TV"** or **"Media"**

4. **If you can't find it:**
   - Turn OFF the DreamMax receiver (unplug it)
   - Wait 30 seconds
   - Tap "Scan" again in Fing
   - See which device **disappears** from the list
   - That's your DreamMax!
   - Turn it back on

5. **Write down the IP address** (looks like: `192.168.1.100`)

---

### Alternative: Router Method

1. Open browser on any device
2. Go to: `192.168.1.1` (or `192.168.0.1`)
3. Log in (check router label for password)
4. Look for "Connected Devices" or "Device List"
5. Find "DreamMax" or "B9S2X"
6. Write down the IP address

---

## ⚙️ Step 3: Configure the App

1. **Open "DreamMax Remote"** from home screen

2. **Tap the Settings icon** (⚙️) in top-right corner

3. **Enter the IP address** you found (e.g., `192.168.1.100`)

4. **Tap "Test"** button
   - If you see **"Connected!"** (green light) - you're done!
   - If you see **"Connection failed!"** - double-check the IP

5. **Tap "Save"**

---

## 🎮 Step 4: Start Using!

The app is ready! All buttons work just like the original remote:

- **Power button** (red) - Turn receiver on/off
- **Number pad** - Enter channel numbers directly
- **Volume/Channel** - Adjust settings
- **D-Pad** (arrows + OK) - Navigate menus
- **Color buttons** (Red, Green, Yellow, Blue) - Special functions
- **Media controls** - Play, pause, rewind, etc.

---

## ⚠️ Troubleshooting

### "Connection Failed" or Red Status Light
- ✅ Make sure iPhone and DreamMax are on the **same Wi-Fi network**
- ✅ Double-check the IP address
- ✅ Ensure the receiver is turned ON
- ✅ Try the "Test" button again

### Buttons Don't Work
- ✅ Check the status light is GREEN
- ✅ Test connection again in Settings
- ✅ Some commands may not work on all firmware versions

### App Won't Open
- ✅ Make sure you installed it from Safari (not Chrome)
- ✅ Try deleting and reinstalling from the link above

---

## 💡 Important Notes

- **Both devices must be on the same Wi-Fi** for the remote to work
- **The IP address is saved** - you only need to enter it once
- **If you move houses** or change networks, you'll need to find the new IP
- **The app works offline** after first load (no internet needed)
